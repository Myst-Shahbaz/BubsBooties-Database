🍼 BubsBooties Database Project

This repository contains the SQL scripts and documentation for the BubsBooties relational database project, designed to showcase skills in SQL, relational modeling, and business intelligence.

-----------------------------------------------------------------------------------------------------------
🔹 Project Overview

The BubsBooties Database tracks and manages business operations, including:

🧑‍🤝‍🧑 Customers – first name, last name, email

👨‍💼 Employees – first name, last name, start date, position

📦 Products – product name, launch date

🛒 Customer Purchases – transaction details linking customers, products, and employees

The database is fully MySQL-compatible, with proper keys, constraints, and data types to ensure data integrity.

-----------------------------------------------------------------------------------------------------------
🔹 Repository Structure

| File              | Description                                                        |
| ----------------- | ------------------------------------------------------------------ |
| `schema.sql`      | `CREATE TABLE` statements for all tables with keys and constraints |
| `sample_data.sql` | Inserts demo data into each table for testing and analysis         |
