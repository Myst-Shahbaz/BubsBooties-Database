# BubsBooties Database Project

## Overview
**BubsBooties** is a relational database project designed to manage customers, employees, products, and purchases for a sample e-commerce platform. The project demonstrates proper relational modeling, foreign key relationships, and sample data for testing.

## Files in this Repository
- **BubsBooties.sql**  
  Contains the full database structure including tables (`customers`, `employees`, `products`, `customer_purchases`) and sample data.

- **BubsBooties ERR Diagram.mwb**  
  The ER diagram visualizing table relationships, primary keys, and foreign keys.

- **README.md**  
  Project overview, structure, and instructions.

## Database Tables
The main tables are:

1. **customers** – Stores customer information.
2. **employees** – Stores employee details.
3. **products** – Stores product information.
4. **customer_purchases** – Tracks customer purchases and associated employees.

## How to Use
1. Open your MySQL or compatible database tool.
2. Run `BubsBooties.sql` to create the database, tables, and insert sample data.
3. Open `BubsBooties ERR Diagram.mwb` in MySQL Workbench to view the ER diagram.
